# 同行｜讓不同世代一起看懂旅程

同行是一個為家族旅行與多人共遊設計的 Web App。它把「誰負責規劃」和「誰只需要跟著走」分成不同角色，讓長輩、孩子與規劃者都能看到同一份最新行程，不必在聊天訊息、試算表和截圖之間反覆確認。

這個版本已經可以在同一台伺服器上讓不同瀏覽器登入、加入同一趟旅程並同步行程；它仍是可運作的開發版本，尚未部署成公開服務，也還沒有完成 iPhone／Android 真機驗收。

## 適合什麼情境

想像一趟跨世代家族旅行：

- 規劃者要安排每天的時間、地點、交通和集合點；
- 旅伴只想快速知道「現在要去哪裡」和「走失去哪裡集合」；
- 有人臨時晚到，要讓其他人看見狀態；
- 網路不穩時，至少還能打開最後同步的行程。

同行把這些需求收進一個大字、清楚、可鍵盤操作的介面，並用伺服器權限保護規劃者的編輯功能。

## 兩種角色

| 角色 | 可以做什麼 |
|---|---|
| 規劃者 | 建立旅程、產生一次性邀請、新增／修改／刪除每日行程與集合點 |
| 旅伴 | 查看共享行程、回報「我到了」或「我會晚一點」，不能覆寫旅程 |

權限不只靠隱藏按鈕。即使旅伴直接呼叫 API，伺服器也會拒絕未授權的修改。

## 從零開始的一次使用流程

1. 規劃者註冊並建立一趟旅程，設定目的地與起訖日期。
2. 系統依日期建立每日行程，規劃者加入時間、地點、交通與集合資訊。
3. 規劃者產生七天內有效、只能使用一次的邀請。
4. 旅伴用另一個瀏覽器註冊並接受邀請。
5. 雙方重新整理後都會看到 SQLite 中的同一份旅程。
6. 旅伴可以更新自己的集合狀態；規劃者的行程修改會透過重新整理、回到視窗或輪詢同步。
7. 伺服器暫時離線時，瀏覽器可以唯讀開啟最後同步的旅程，不會假裝離線修改成功。

## 已完成的核心能力

- 註冊、登入、登出與 HttpOnly 工作階段。
- 密碼使用 scrypt 加鹽雜湊，不以明文保存。
- SQLite 保存帳號、旅程、成員、邀請與操作結果。
- 一次性邀請、規劃者／旅伴權限與共享行程 CRUD。
- 版本號避免舊資料靜默覆蓋，操作識別碼避免重複提交。
- 同步中、離線、衝突與未保存狀態都有文字說明。
- IndexedDB 保存最後同步的唯讀快取。
- Google Maps 路線在外部開啟，不把本 App 當成導航工具。
- Service Worker 快取 App 外殼，首次上線後可離線重新開啟。
- 320px、390px、大字體、鍵盤焦點與基本無障礙支援。

## 尚未完成

- 拖拉排序、跨日移動、共同規劃者與細粒度衝突處理。
- 邀請撤銷、移除成員、通知、郵件驗證與工作階段管理。
- 公開 HTTPS 部署、備份／還原、監測與限流。

因此，這個 repository 應視為「可運作的多人開發版」，不是已通過正式上線驗收的 MVP。

## 本機執行

需要 Node.js 22 以上，因為後端直接使用 Node 內建的 `node:sqlite`。不需要申請外部 API key。

```powershell
npm install
npm run build
npm start
```

終端機顯示 `http://localhost:8787` 後，用瀏覽器開啟即可。第一次註冊時，伺服器會在 `var/together-travel.sqlite` 建立本機資料庫；`var/` 已排除版本控制。

若要同時修改前端與後端，可開兩個終端機：

```powershell
npm run dev:api
npm run dev
```

第一個指令啟動 API，第二個啟動 Vite 前端開發伺服器。

## 驗證

```powershell
npm run check
npm audit --audit-level=moderate
```

`npm run check` 會執行前端互動、資料保存、無障礙、SQLite 多人權限情境、TypeScript 檢查與正式版建置。它證明程式的自動化驗收狀態，但不能取代實體手機測試。

## 資料與隱私

- 真實使用資料只會寫入執行這個專案的 SQLite 檔案與使用者瀏覽器 IndexedDB。
- `var/`、建置輸出、log、測試結果與相依套件都不會進入 Git。
- repository 內的帳號、姓名、電話與旅程都是明確的測試／示例資料，不是實際使用者資料。
- 公開部署前仍應加入 HTTPS、備份、限流、郵件驗證與正式隱私政策。

## 技術結構

- `src/AuthenticatedApp.tsx`：帳號、旅程選擇、同步與角色流程。
- `src/App.tsx`：每日行程、集合點、狀態與高齡友善介面。
- `src/api.ts`：瀏覽器端 API client。
- `src/trip-cache.ts`：IndexedDB 離線唯讀快取。
- `server/app.mjs`：HTTP API、權限、SQLite schema 與靜態檔案服務。
- `public/`：PWA manifest、圖示與 Service Worker。

這個 GitHub 版本只保留可執行產品、必要設定、測試與這份說明；PRD、QA 流水帳、研究報告、log、資料庫與建置產物不包含在提交中。
