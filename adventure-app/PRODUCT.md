# 同行 · Together

手機優先的多人同行 app。開場是冒險大廳，隊員可以聊天與發送表情貼圖；隊長選擇西門町地圖和集合地，開始冒險後全隊切換到滿版手繪地圖。

## 可用操作

- 預設四人示範，可點選角色切換旅人。
- 開啟新旅程與透過邀請連結加入；最多十二人。
- 隊長設定集合地、開始冒險、調整集合旗幟。
- 每人選擇下一站，呈現頭像沿路移動的動畫，並自行確認抵達。
- 手繪地圖可拖曳及縮放。角色在大廳以紙片旅人顯示，地圖上以圓形頭像顯示。
- 大廳聊天室與六款表情貼圖；近期訊息短暫顯示於角色上方。
- 真實房間每三秒同步，訊息與位置狀態保存在 D1；房間有效期七天。

西門町是第一張可用地圖。地圖是簡化示意，位置由本人回報，路線動畫不代表 GPS 或實際導航路線。公開邀請前，需先在網站分享設定中開放朋友存取。

## 開發與驗證

```powershell
npm install
npm run dev
node --test test/rooms.test.mjs
node node_modules/typescript/bin/tsc --noEmit
npm run build
```

測試須在已套用本機 D1 遷移的服務上執行。test/rooms.test.mjs 覆蓋兩位旅人的加入、聊天、貼圖、隊長權限、冒險開始、独立移動、提前抵達及房間隔離。

原始圖片使用內建 imagegen 製作，專案使用 public/art/lobby.png、public/art/ximen-map.png、public/art/travelers.png。提示主題分別為：Wildermyth 紙片民俗插畫感的西門町暮光廣場；稀疏且可讀的手繪平面街區及知名店家圖示；四位現代旅人透明背景角色圖。未使用遊戲原始素材。
